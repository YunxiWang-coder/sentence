About the Project

About This Website

Wise Proverbs is a simple student website built to practice HTML, CSS, and JavaScript. It contains a small collection of English proverbs and their meanings.

The website includes three pages: Home, Proverbs, and About. It uses responsive design, semantic HTML tags, card layouts, and basic JavaScript interaction.

Features

  • Responsive navigation bar
  • Beautiful card layout
  • Random proverb generator
  • Smooth hover effects
  • Mobile-friendly design
